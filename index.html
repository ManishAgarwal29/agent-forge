How it works

Grounded by design

Every agent Forge writes answers only from the site facts you give it, says so when it does not know, and treats visitor text as data. Forge warns you when facts are missing, still sample text, or so long that every visitor pays for them on every call.

Checked as the spec says

The linter reads the files your draft would publish, the way a calling browser does, and applies the same checks to a draft or a live site: MUST, SHOULD and MAY requirements, credentials in public text, peer allow-lists, execution limits. Try it on a published site from the command line:

node validator/cli.mjs <network URL>

Callable by other sites

Forge is itself an open agentic website. Its action bridge shares validate_site and get_starter_templates, so another site's agents can check a peer before they call it, or pick a starting template.

Spec: Minimum Viable Specification for a Worldwide Agentic Web. Forge checks that a site is well formed. It does not run your agents against test questions, so a passing score does not prove the answers are right: use the Try it tab for that.

Agent Forge is open source (Apache 2.0). The browser runtime in runtime/ is nsdeploy's (Apache 2.0), taken as published in the agentic-web repository's agentify-website skill.
